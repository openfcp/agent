# OpenFCP 开放消保部

**金融消费者权益保护 AI 智能体系统** —— 一款专为金融机构消保部门打造的桌面 AI 助理，一键安装，即开即用。

> 当前版本：`1.0.1-free`（个人免费版）

OpenFCP 把金融机构消费者权益保护部门各岗位的日常工作任务 SOP、岗位职责、项目流程、主要用到的制度文件、常用的模板话术，全部从资深从业多年的专业人士手中萃取而来，沉淀在一套桌面应用里。它不是简单的 AI 问答机器人，而是一个可以独立承担消保部门日常工作的 AI 团队。

主智能体「小O」就是消保部主管，带着六个子智能体也就是六位员工，覆盖审查、投诉、教育宣传、检查、合规、综合管理六大岗位，基本上可以覆盖整个消保部门的日常工作。

工作模式上，它不仅是传统的 AI 问答：可以帮你写报告、制图表、做方案、设计 PPT 框架、统计分析投诉数据、撰写金融教育短视频文案，还能帮你检查消保评价资料文件夹——让你的工作量直接减半。

## 快速开始

### 一、下载安装

#### Windows

1. 前往项目 [Releases 页面](https://github.com/OpenFCP/openfcp/releases)
2. 下载 `OpenFCP_1.0.1_x64-setup.exe`（或 `OpenFCP_1.0.1_x64_zh-CN.msi`）
3. 双击运行安装程序，按提示完成安装
4. 安装完成后，从「开始菜单」启动 OpenFCP

> 如果 SmartScreen 提示"Windows 已保护你的电脑"，点击「更多信息」→「仍要运行」。这是由于软件未购买代码签名证书，属正常现象。

#### macOS（仅 Apple Silicon，M 系列芯片）

1. 前往项目 [Releases 页面](https://github.com/OpenFCP/openfcp/releases)
2. 下载 `OpenFCP_v1.0.1.dmg`
3. 双击打开 `.dmg`，将 OpenFCP 图标拖入「Applications」文件夹
4. 从「启动台」打开 OpenFCP

> 首次启动时如果提示"无法验证开发者"或"来自身份不明的开发者"：
> 打开「系统设置」→「隐私与安全性」→ 拉到底部点击「仍要打开」→ 输入密码确认。这也是由于未购买 Apple Developer 证书，属正常现象。

> **说明**：当前 macOS 版本仅提供 Apple Silicon（M1/M2/M3/M4）版本。如需 Intel 芯片版本，请发送邮件至 support@openfcp.com 留言，我们将根据需求提供。

---

### 二、申请大模型 API Key

OpenFCP 需要一个大模型 API Key 才能工作。你可以使用任何兼容 OpenAI 接口的国内外主流大模型厂商（如 DeepSeek、通义千问、智谱 GLM、月之暗面 Kimi、文心一言、百川智能、豆包、MiniMax、阶跃星辰、零一万物，以及 OpenAI 等）。

**下面以 DeepSeek 为例**（个人注册即送余额，价格便宜，推荐使用）：

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)
2. 注册账号（手机号一键注册）
3. 登录后进入控制台 → 左侧「API Keys」
4. 点击「创建 API Key」，复制生成的 `sk-xxxxxxxxxxxxxxxx` 字符串
5. 充值：点击「充值」按钮，首次充值 10 元即可使用很久（约 1000 万 tokens）

> 如使用其他厂商，将对应的 API 地址和 Key 填入设置页的「自定义（兼容 OpenAI）」即可。

> **隐私说明**：API Key 仅保存在本地配置文件中，不会上传到任何服务器。所有对话通过对应大模型厂商的服务器处理，数据使用遵循各厂商隐私政策。

---

### 三、配置与使用

1. 启动 OpenFCP，首次进入会显示欢迎页面
2. 点击右上角「设置」→「模型配置」→「添加模型」
3. 从下拉列表中选择对应的大模型厂商（如 DeepSeek），或在「自定义（兼容 OpenAI）」中填写其他厂商信息
4. 将申请的 API Key 粘贴到 `API Key` 输入框，点击保存
5. 回到主页，在对话框输入问题即可开始工作

> 首次启动会自动初始化内置的 11 部金融消保法规知识库，耗时约 1-2 秒。

## 技术说明

- **架构**：Tauri 2 + Rust + Vue 3
- **前端**：Vue 3 + TypeScript + Pinia
- **后端**：Rust（异步 LLM 调用、知识库检索、子智能体调度）
- **数据库**：SQLite（本地存储，所有数据不离设备）
- **大模型**：默认 DeepSeek API，兼容 OpenAI 接口，可自行替换为其他主流厂商
- **安装包大小**：约 15-25 MB（远小于 Electron 应用）
