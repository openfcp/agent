# OpenFCP 开放消保部

**金融消费者权益保护 AI 智能体系统** —— 一款专为金融机构消保部门打造的桌面 AI 助理，一键安装，即开即用。

> 当前版本：`1.0.1-free`（个人免费版）

OpenFCP 把金融机构消费者权益保护部门各岗位的日常工作任务 SOP、岗位职责、项目流程、主要用到的制度文件、常用的模板话术，全部从资深从业多年的专业人士手中萃取而来，沉淀在一套桌面应用里。它不是简单的 AI 问答机器人，而是一个可以独立承担消保部门日常工作的 AI 团队。

主智能体「小O」就是消保部主管，带着六个子智能体也就是六位员工，覆盖审查、投诉、教育宣传、检查、合规、综合管理六大岗位，基本上可以覆盖整个消保部门的日常工作。

工作模式上，它不仅是传统的 AI 问答：可以帮你写报告、制图表、做方案、设计 PPT 框架、统计分析投诉数据、撰写金融教育短视频文案，还能帮你检查消保评价资料文件夹——让你的工作量直接减半。

## 快速开始

### 一、系统要求

| 项目 | 要求 |
|---|---|
| Windows | Windows 10（1809 及以后）/ Windows 11，x64 |
| macOS | macOS 12 Monterey 及以上，仅 Apple Silicon（M1/M2/M3/M4） |
| 内存 | 建议 4 GB 及以上 |
| 磁盘 | 安装包约 5–8 MB，安装后占用以实际应用为准 |
| 网络 | 调用大模型 API 需要联网；知识库检索在本地完成 |

> 当前 macOS 版本仅提供 Apple Silicon 版本；如需 Intel 芯片版本，请发送邮件至 support@openfcp.com 留言，我们将根据需求提供。

### 二、下载安装

#### Windows

1. 前往项目 [Releases 页面](https://github.com/openfcp/agent/releases)
2. 下载 `OpenFCP_1.0.1_x64-setup.exe`（或 `OpenFCP_1.0.1_x64_zh-CN.msi`）
3. **（建议）校验安装包 SHA256**，确认文件未被篡改（方法见下方「安装包校验」）
4. 双击运行安装程序，按提示完成安装
5. 安装完成后，从「开始菜单」启动 OpenFCP

> 如果 SmartScreen 提示"Windows 已保护你的电脑"，点击「更多信息」→「仍要运行」。这是由于软件未购买代码签名证书，属正常现象，建议先完成 SHA256 校验再运行。

#### macOS（仅 Apple Silicon，M 系列芯片）

1. 前往项目 [Releases 页面](https://github.com/openfcp/agent/releases)
2. 下载 `OpenFCP_v1.0.1.dmg`
3. **（建议）校验安装包 SHA256**（方法见下方「安装包校验」）
4. 双击打开 `.dmg`，将 OpenFCP 图标拖入「Applications」文件夹
5. 从「启动台」打开 OpenFCP

> 首次启动时如果提示"无法验证开发者"或"来自身份不明的开发者"：
> 打开「系统设置」→「隐私与安全性」→ 拉到底部点击「仍要打开」→ 输入密码确认。这也是由于未购买 Apple Developer 证书，属正常现象，建议先完成 SHA256 校验再打开。

#### 安装包校验

软件未做代码签名，下载后建议核对 SHA256，确认文件未被篡改。各安装包官方校验值如下（对应 `v1.0.1-free`）：

| 文件 | SHA256 |
|---|---|
| `OpenFCP_1.0.1_x64-setup.exe` | `19751169bfd74f20ae660503e19e4e693fcf8c821cacf15d7ea27f2f020ef6f8` |
| `OpenFCP_1.0.1_x64_zh-CN.msi` | `9698fd7f9a3cd749dfb62af084c6c476c80d41b922a213f7f096e18d750b7e16` |
| `OpenFCP_v1.0.1.dmg` | `26e746cfce83038e282927345caa07615044484fdfbf01f843c119b2a8ad70de` |

校验命令（把命令中的文件名换成实际下载的文件）：

```sh
# macOS / Linux
shasum -a 256 OpenFCP_v1.0.1.dmg

# Windows（PowerShell）
certutil -hashfile OpenFCP_1.0.1_x64-setup.exe SHA256
```

将输出的值与上表比对，一致即可确认文件完整、未被篡改。

### 三、申请大模型 API Key

OpenFCP 需要一个大模型 API Key 才能工作。你可以使用任何兼容 OpenAI 接口的国内外主流大模型厂商（如 DeepSeek、通义千问、智谱 GLM、月之暗面 Kimi、文心一言、百川智能、豆包、MiniMax、阶跃星辰、零一万物，以及 OpenAI 等）。

**下面以 DeepSeek 为例**（个人注册即送余额，价格便宜，推荐使用）：

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)
2. 注册账号（手机号一键注册）
3. 登录后进入控制台 → 左侧「API Keys」
4. 点击「创建 API Key」，复制生成的 `sk-xxxxxxxxxxxxxxxx` 字符串
5. 充值：点击「充值」按钮，首次充值 10 元即可使用很久（约 1000 万 tokens）

> **隐私说明**：API Key 仅保存在本地配置文件中，不会上传到任何服务器。所有对话通过对应大模型厂商的服务器处理，数据使用遵循各厂商隐私政策。

### 四、配置与使用

1. 启动 OpenFCP，首次进入会显示欢迎页面
2. 点击右上角「设置」→「模型配置」→「添加模型」
3. 从下拉列表中选择对应的大模型厂商（如 DeepSeek），或在「自定义（兼容 OpenAI）」中填写其他厂商信息
4. 将申请的 API Key 粘贴到 `API Key` 输入框，点击保存
5. 回到主页，在对话框输入问题即可开始工作

> 首次启动会自动初始化内置的 11 部金融消保法规知识库，耗时约 1-2 秒。

#### 模型配置说明（自定义 / 兼容 OpenAI）

选择「自定义（兼容 OpenAI）」时需要填写三项：

- **Base URL（API 地址）**：填厂商提供的 OpenAI 兼容接口根地址。**是否带 `/v1` 取决于厂商**，请以各厂商官方文档为准，多数兼容接口会以 `/v1` 结尾。
- **模型名称（Model ID）**：填该厂商具体的模型标识，不要用显示名称。
- **API Key**：厂商控制台生成的密钥。

常见厂商填写示例（**仅供快速参考，可能随厂商调整，请以官方文档为准**）：

| 厂商 | Base URL（参考） | 模型名称示例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat`、`deepseek-reasoner` |
| 通义千问（兼容模式） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4` |
| 月之暗面 Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o` |

> 关于推理模型、流式输出、超时与代理等能力是否可用，取决于所选厂商及其接口；如遇连接问题，请优先核对 Base URL 与模型名称，详见下方「常见问题」。

### 五、常见问题（FAQ）

**Q：填入 API Key 后提示无效 / 401 认证失败？**
- 确认 Key 复制完整、无多余空格；
- 确认 Key 所属厂商与当前选择的模型厂商一致；
- 到厂商控制台确认 Key 未被禁用或删除。

**Q：调用报 429 限流 / 余额不足？**
- 到厂商控制台检查账户余额，余额不足请先充值；
- 429 表示请求过于频繁或触发厂商限流，稍后重试或降低调用频率。

**Q：首次启动知识库初始化失败？**
- 确认安装目录有读写权限，重启应用重试；
- 若反复失败，请通过 support@openfcp.com 反馈，并附上系统版本信息。

**Q：公司网络需要代理怎么办？**
- 目前通过系统代理设置接入网络：在操作系统层面配置 HTTP/HTTPS 代理后重启应用；
- 如代理环境特殊（如需认证的企业代理）导致无法连接，请邮件反馈具体环境。

**Q：生成中断后如何恢复？**
- 可直接在当前对话中重新发送指令继续；内容较长时建议先「新建任务」再分段处理，避免单次输出过长。

> 更多问题欢迎通过 [GitHub Issues](https://github.com/openfcp/agent/issues) 反馈或发邮件至 support@openfcp.com。

## 知识库说明

首次启动会自动初始化内置的金融消保法规知识库（约 11 部），用于法规咨询、概念解释、时限查询与监管口径解读。

**覆盖的法规层级**：涵盖消费者权益保护相关的法律、行政法规、部门规章与规范性文件。代表性法规包括《中华人民共和国消费者权益保护法》及其实施条例、《银行保险机构消费者权益保护管理办法》《银行业保险业消费投诉处理管理办法》等。

> 具体收录的法规名称、版本与生效日期，以应用内「知识库」页面显示为准。法规更新后如何同步，请关注后续版本说明或通过 support@openfcp.com 咨询。

**关于导入自有文档**：当前免费版以内置法规知识库为主，是否支持导入本单位制度、产品条款或历史台账，以及导入格式与操作方式，请以应用内实际功能为准；如有明确需求，欢迎邮件反馈。

**数据流向**：知识库检索在本地完成，不上传你的文档内容；仅对话内容会发送至你所选择的大模型厂商服务器用于生成回答。

## 数据与隐私

- **存储方式**：本地 SQLite 数据库，业务数据默认保存在本机，不上传服务器。
- **数据位置**：应用数据目录因操作系统而异（Windows 通常位于 `%APPDATA%` 下的应用目录，macOS 通常位于 `~/Library/Application Support/` 下对应应用的目录），具体路径以应用内设置为准。
- **备份与迁移**：需要迁移到新机器时，可先退出应用，再拷贝上述应用数据目录到新机器的相同位置；操作前建议先完整备份。
- **卸载清理**：卸载应用不会自动删除配置、API Key 与对话记录。如需彻底清理，请在卸载后手动删除对应的应用数据目录。
- **API Key**：仅保存在本地配置文件中，不会上传到任何服务器。
- **敏感信息提示**：对话内容会发送至所选大模型厂商的服务器处理，请勿在对话中输入身份证号、银行卡号、客户姓名等敏感个人信息或涉密资料；使用前请遵循所在单位的数据安全与合规要求。

## 技术说明

- **架构**：Tauri 2 + Rust + Vue 3
- **前端**：Vue 3 + TypeScript + Pinia
- **后端**：Rust（异步 LLM 调用、知识库检索、子智能体调度）
- **数据库**：SQLite（本地存储，所有数据不离设备）
- **大模型**：默认 DeepSeek API，兼容 OpenAI 接口，可自行替换为其他主流厂商
- **安装包大小**：约 5–8 MB（Windows setup 约 5 MB、MSI 约 7 MB、macOS dmg 约 8 MB，远小于 Electron 应用）
